# Dialect support

What each dialect writes for the changes and features of a migration.
For the database types of columns, refer to [Column types](../schemas/column-types.md).

## Minimum versions

| Database   | Minimum version |
| ---------- | --------------- |
| PostgreSQL | `13`            |
| MariaDB    | `11.4`          |
| SQL Server | `2017`          |
| SQLite     | `3.35`          |

## Changes

| Change                                  | PostgreSQL                             | MariaDB                                            | SQL Server                             | SQLite                                |
| --------------------------------------- | -------------------------------------- | -------------------------------------------------- | -------------------------------------- | ------------------------------------- |
| Create a table                          | `CREATE TABLE`                         | `CREATE TABLE`                                     | `CREATE TABLE`                         | `CREATE TABLE`, with its foreign keys |
| Rename a table                          | `RENAME TO`, `RENAME CONSTRAINT`       | `RENAME TO`                                        | `sp_rename`                            | `RENAME TO`                           |
| Move a table to another database schema | `SET SCHEMA`                           | `RENAME TABLE`                                     | `ALTER SCHEMA ... TRANSFER`            | not supported                         |
| Add a column                            | `ADD COLUMN`                           | `ADD COLUMN`                                       | `ADD`                                  | `ADD COLUMN`, or a rebuild            |
| Rename a column                         | `RENAME COLUMN`                        | `RENAME COLUMN`                                    | `sp_rename`                            | `RENAME COLUMN`                       |
| Change a column                         | `ALTER COLUMN`                         | `MODIFY COLUMN`                                    | `ALTER COLUMN`                         | a rebuild                             |
| Change a primary key                    | `DROP CONSTRAINT`, `ADD CONSTRAINT`    | `DROP PRIMARY KEY, ADD PRIMARY KEY`                | `DROP CONSTRAINT`, `ADD CONSTRAINT`    | a rebuild                             |
| Drop an index                           | `DROP INDEX`                           | `DROP INDEX ... ON`                                | `DROP INDEX ... ON`                    | `DROP INDEX`                          |
| Add a foreign key                       | `ADD CONSTRAINT`                       | `ADD CONSTRAINT`                                   | `ADD CONSTRAINT`                       | a rebuild                             |
| Drop a foreign key                      | `DROP CONSTRAINT`                      | `DROP FOREIGN KEY`                                 | `DROP CONSTRAINT`                      | a rebuild                             |
| Add or drop a check                     | `ADD CONSTRAINT`, `DROP CONSTRAINT`    | `ADD CONSTRAINT`, `DROP CONSTRAINT`                | `ADD CONSTRAINT`, `DROP CONSTRAINT`    | a rebuild                             |
| Set a comment                           | `COMMENT ON`                           | `COMMENT` in the column, `ALTER TABLE ... COMMENT` | the `MS_Description` extended property | nothing                               |
| Add identity to a column                | `ADD GENERATED BY DEFAULT AS IDENTITY` | `MODIFY COLUMN ... AUTO_INCREMENT`                 | not supported                          | nothing, the rowid                    |
| Remove identity from a column           | `DROP IDENTITY`                        | `MODIFY COLUMN`                                    | not supported                          | nothing, the rowid                    |

## Features

| Feature              | PostgreSQL                                       | MariaDB              | SQL Server                             | SQLite                                    |
| -------------------- | ------------------------------------------------ | -------------------- | -------------------------------------- | ----------------------------------------- |
| Identity             | `GENERATED BY DEFAULT AS IDENTITY`               | `AUTO_INCREMENT`     | `IDENTITY(1, 1)`, only in a new column | the rowid                                 |
| Current time default | `CURRENT_TIMESTAMP`                              | `(UTC_TIMESTAMP(6))` | `SYSUTCDATETIME()`                     | `(strftime('%Y-%m-%dT%H:%M:%f', 'now') \|\| '000Z')` |
| Current date default | `((CURRENT_TIMESTAMP AT TIME ZONE 'UTC')::date)` | `(UTC_DATE())`       | `CAST(SYSUTCDATETIME() AS DATE)`       | `(date('now'))`                           |
| Random UUID default  | `gen_random_uuid()`                              | `(UUID())`           | `NEWID()`                              | an expression with `randomblob`           |
| Partial index        | yes                                              | no                   | yes, a filtered index                  | yes                                       |
| Descending index     | yes                                              | yes                  | yes                                    | yes                                       |
| Database schemas     | yes                                              | yes, as databases    | yes                                    | no                                        |
| Collation            | `COLLATE "name"`                                 | `COLLATE name`       | `COLLATE name`                         | `COLLATE name`                            |
| Comments             | yes                                              | yes                  | yes                                    | no                                        |
| Batch separator      | none                                             | none                 | `GO`                                   | none                                      |

SQLite keeps times as text. Its current time default gives UTC with six digits of fraction, such as
`2026-01-05T10:00:00.123000Z`, so it compares as text with times that clients write to the microsecond. SQLite counts
to the millisecond, so the last three digits are 0.

A change that a database does not support stops leadseal with an `UnsupportedChangeException`.
Refer to [Troubleshooting dialects](troubleshooting-dialects.md).
